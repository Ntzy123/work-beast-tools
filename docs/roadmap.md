## ✨ 待办功能

### 1️⃣ 软件更新功能

**所属模块**：全局 / 设置页

**描述**：  
为软件增加更新检测与升级能力，支持检查新版本、获取下载地址，并引导用户完成安装。

**目标**：
- [ ] 实现版本检测机制（本地与远端比对）
- [ ] 检测到新版本时弹窗提醒
- [ ] 提供下载入口及跳转链接（调用默认浏览器打开）
- [ ] 支持下载安装包并引导用户安装
- [ ] 允许用户选择「取消」或「跳过此版本」
